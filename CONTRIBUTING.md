# Contributing to Castle Rock Agent

First off, thank you for considering contributing to Castle Rock Agent! It's people like you that make this tool better for everyone.

## Where to Start?

1. **Bug Reports & Feature Requests**: Please use the GitHub Issue Tracker to report bugs or request features. Check if an issue already exists before opening a new one.
2. **Pull Requests**: We gladly accept Pull Requests! 

## Development Process

1. Fork the repository and create your branch from `main`.
2. Ensure you have Go 1.22+ installed.
3. If you've added code that should be tested, please add some tests.
4. Ensure the test suite passes (`go test ./...`).
5. Make sure your code follows standard Go formatting (`go fmt ./...`).

## Pull Request Guidelines

- Keep pull requests small and focused on a single feature or bug fix.
- Write clear, descriptive commit messages.
- Always update the documentation (`README.md` and `README.pt-BR.md`) if you are adding or changing features.

## Need Help?
Feel free to open a draft PR if you need feedback or help with your implementation. We're happy to guide you!
